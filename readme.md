\# Simple Calculator



Simple Calculator is an NVDA add-on that allows you to perform arithmetic calculations quickly and accurately directly from the NVDA screen reader.



\*\*Author:\*\* Mister Anas



\## Installation



You can install this add-on from the NVDA Add-on Store or download it from the \[Releases page](https://github.com/mesteranas/SimpleCalculator/releases).



\## Usage



To open the calculator, press \*\*NVDA+Alt+S\*\* or access it from the \*\*Tools\*\* menu in NVDA.



\*\*Note:\*\* This keyboard shortcut can be changed through NVDA's \*\*Input Gestures\*\* dialog.



When the add-on opens, focus is automatically placed in the input field, where you can type your calculation.



\### Input Format



Simple Calculator uses standard computer-style mathematical expressions. This means that some mathematical symbols are different from those used in school textbooks.



\#### Basic Operations



| Operation      | Symbol | Example |

| -------------- | ------ | ------- |

| Addition       | `+`    | `5+3`   |

| Subtraction    | `-`    | `10-4`  |

| Multiplication | `\*`    | `6\*7`   |

| Division       | `/`    | `20/5`  |

| Power          | `\*\*`   | `2\*\*3`  |



\#### Examples



Correct:



\* `5+3`

\* `10\*5`

\* `100/4`

\* `(5+3)\*2`

\* `2\*\*3`



Incorrect:



\* `5×3` (use `\*` instead of `×`)

\* `10÷2` (use `/` instead of `÷`)

\* `2^3` (use `\*\*` instead of `^`)

\* `5(3+2)` (write `5\*(3+2)`)



\#### Using Parentheses



Parentheses can be used to control the order of calculations.



Example:



\* `2+3\*4` = 14

\* `(2+3)\*4` = 20



\#### Decimal Numbers



Use a period (`.`) as the decimal separator.



Examples:



\* `3.14`

\* `12.5\*2`



\#### Advanced Examples



\* Calculate the area of a rectangle:



&#x20; \* `5\*8`

\* Calculate a discount:



&#x20; \* `100-(100\*0.2)`

\* Calculate the average of three numbers:



&#x20; \* `(10+20+30)/3`

\* Calculate the square of a number:



&#x20; \* `7\*\*2`



\#### Notes



\* Spaces are optional.

\* Expressions must follow standard computer syntax.

\* Invalid expressions will result in an error message.



After entering your expression, press \*\*Tab\*\* to move to the result field and the \*\*Copy\*\* button.
